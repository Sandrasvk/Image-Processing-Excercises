#  Computer Vision & Image Processing Excercises

​This repository contains a series of technical assignments focused on mastering Digital Image Processing and Automated Segmentation techniques. These modules demonstrate the transition from basic pixel manipulation to complex algorithmic workflows.

​🛠️ Tech Stack

​Language: Python

​Libraries: OpenCV (cv2), NumPy, Matplotlib

​Environment: Jupyter Notebooks

​🚀 Completed Learning Modules

​1. Foundational Image Preprocessing

​Implemented core operations including image loading, resizing, and color-space transformations.

​Focused on noise reduction and preparation of raw image data for downstream tasks.

​2. Advanced Segmentation: The Watershed Algorithm

​Developed a multi-step pipeline to separate overlapping objects (e.g., coins_image.jpg).

​Techniques used: Distance Transform, Marker-based flooding, and Connected Components labeling.

​3. Morphological Operations & Noise Control

​Applied Erosion and Dilation to refine object boundaries.

​Implemented Opening (MORPH_OPEN) to successfully remove background salt-and-pepper noise.

​Utilized Morphological Gradient to extract high-contrast object outlines.

​4. Custom Utility Functions

​Developed modular Python functions for consistent image display and array handling.

​Optimized workflows for handling large-scale visualization within notebooks.
